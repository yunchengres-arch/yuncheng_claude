# Product context

雲承：嘉義市西區新榮路 177 號的雲南過橋米線店。資料來源：`../雲承/菜單.docx`、`../雲承/雲承/品牌故事.docx`、`../雲承/雲承/IG產品介紹/產品敘述.docx`（2026-11-12 整理）。菜單價格以 docx 為準，可能不是最新版（例如沒有冷香芽），對外使用前請和 JAY 確認。

**品牌故事（可用於行銷）**
- 爺爺在文革時期帶全家逃到緬甸，後來在台北木柵開雲南料理館，經營 28 年
- 第三代在嘉義創立「雲承」，意思是雲南的傳承。招牌是過橋米線，搭配大薄片、椒麻雞等雲南小菜
- 過橋米線的傳說：書生寒窯苦讀，妻子為了讓他在寒冬吃到保溫又營養的一餐，把熱湯和米線、配料分開裝，吃的時候再合在一起

**菜單（內用價以 `雲承成本與外送定價試算-2.xlsx`「價格試算」為準，JAY 2026-11-12 確認）**
- 過橋米線：日・雲上菌湯 260（推，大骨雞湯＋牛肝菌）、月・滇南酸果 240（推，酸木瓜，微酸開胃）、星・酸潮映紅 250（酸辣，辣度兩顆星）、雲・滇味本心 230（原汁原味）、涼拌米線 150
- 單點：雲承秘製椒麻雞 內用 180／Uber 230（6 兩去骨雞腿）、大薄片 160、皮蛋豆腐 50、小黃瓜 50（嘉義小農溫室有機）、冷香芽 50（＝成本表「醃菜豆芽」）
- 店內服務（JAY 2026-11-12 確認）：過橋米線主餐可再續米線一次；有套餐搭配；出餐可選「直接出餐」或「桌邊服務」；湯不夠熱可請店員加熱；IG 有周邊停車場文章
- **豌豆粉已下架**（2026-11-12），文案不要提；品牌故事中的豌豆粉也略過

- 吃法（用餐小卡「壹鍋伍步」）：食材放入砂鍋、先葷後素、蓋鍋靜置 3 分鐘、倒入米線、先喝湯後吃米線
